# AetherOS — Aether Agent Suite

You are the AI assistant helping the user launch and operate the **Aether Agent Suite**.
Your goal is zero friction setup and seamless agent collaboration.

## Immediate First-Run Actions (on first greeting):
1. **Environment Check**: Verify Node.js LTS (v20+) is available (`node -v`).
2. **Setup Studio Workspace**:
   - Navigate to `aether-studio/` (`cd aether-studio`).
   - If `.env.local` does not exist: copy from `.env.example` (`cp .env.example .env.local`).
   - If `node_modules/` does not exist: run `npm install`.
3. **Launch Dev Server**:
   - Run `npm run dev` inside `aether-studio/`.
4. **Open Browser**:
   - Direct user to `http://localhost:3000`.
5. **Confirm Ready**:
   - State: "Your **Aether Agent Suite** is active at http://localhost:3000 🎉 Enter your Anthropic API key in the onboarding dialog or in `aether-studio/.env.local`."

## Repository Architecture & Core Agents:
- `aether-studio/`: Next.js 16 + React 19 + Tailwind CSS web dashboard & agent execution engine.
- `.claude/agents/`: Specialized agent system prompts and operational knowledge:
  - `ecommerce.md`: **Valkyrie** — E-Commerce, UGC & Video Product Studio
  - `fireflies.md`: **Echo** — Meeting Intelligence & Voice Call Transcripts
  - `createur-contenu.md`: **Muse** — Content Studio & Editorial Carousels
  - `veille.md`: **Pulse** — Trend Intelligence & Viral Pattern Analysis
  - `prospection.md`: **Hunter** — Autonomous Outbound & HyperReach™ Prospecting Engine
  - `proposition.md`: **Closer** — Commercial Proposals & Deal Closer
  - **Nexus**: Unified Multi-Agent Orchestrator connecting all specialized modules
- `clients/`: Client brand context (e.g., `clients/votre-marque/brand.md`).
- `content/`, `propositions/`, `meetings/`, `analytics/`: Deliverable outputs generated by agents.

## Guidelines:
- Never commit API keys or sensitive credentials.
- All web interface code belongs in `aether-studio/`.
- Unlocking or locking agents is managed via `OWNED_AGENT=` in `aether-studio/.env.local`.
